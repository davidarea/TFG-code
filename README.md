# Agent-Based Financial Market Simulation

## Overview

This project implements an agent-based model (ABM) of a financial market in which multiple investors interact by buying and selling shares of a single asset.

All agents start with the same initial wealth but differ in how they weight the investment parameters used to make trading decisions. These heterogeneous preferences influence their behavior and, through their interactions, the evolution of the asset price over time.

The model simulates market dynamics over a given time horizon, allowing the resulting price time series to be analyzed.

## Objectives

- Simulate a financial market populated by heterogeneous investors.
- Model trading decisions based on different weightings of investment parameters.
- Analyze the evolution of stock prices over time.
- Explore how differences in investor behavior affect market dynamics.

## Methodology

The simulation follows an agent-based modeling approach. Each investor is represented as an individual agent with an initial wealth endowment and a set of investment preferences. Agents use these preferences to make buying and selling decisions, generating price dynamics through their interactions.
